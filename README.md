## Cara update di GitHub
1. Buka repo `Chaii154/ROYAL-LOUNGE-CLUB`.
2. Klik `index.html` yang lama → pensil (Edit) → Select All → Delete → paste isi `index.html` yang baru ini → **Commit changes**.
3. (Opsional) hapus file `royal-logo.png`, `royal-banner.jpg`, `royal-poster.jpg` dari repo karena sudah tidak dipakai lagi — klik masing-masing file → ikon tempat sampah → Commit. Tidak wajib dihapus, tapi boleh biar repo lebih rapi.
4. Tunggu 1–2 menit, buka `https://chaii154.github.io/ROYAL-LOUNGE-CLUB/` dan hard refresh (Ctrl+Shift+R / Cmd+Shift+R).
